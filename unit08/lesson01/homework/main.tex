\textbf{2.}\quad Using $g(t) = (t^2 - 2t,\; t - 1)$, $-1 \le t \le 3$:

\vspace{4pt}
(a)\quad Solve for $t$ when $y(t) = 2$. State the position of the
particle at that time.
\writelines{3}

\vspace{0.04in}
(b)\quad Solve for $t$ when $y(t) = 0$. State the position of the
particle at that time.
\writelines{2}

\vspace{0.10in}
\textbf{3.}\quad The curve crosses the $y$-axis at two different points
(two values of $t$ give $x(t) = 0$).

\vspace{4pt}
(a)\quad Find both values of $t$ where $x(t) = 0$. Show your algebra.
\writelines{3}

(b)\quad Write the coordinates of both points where the curve crosses
the $y$-axis.
