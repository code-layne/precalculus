\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can evaluate $x(t)$ and $y(t)$ at given values of the parameter $t$
    and record each result as an ordered pair $(x,\, y)$.
  \item I can construct a graph of a parametric function by plotting ordered
    pairs from a table in order of increasing $t$, including marking the
    direction of the curve with arrows.
  \item I can identify the start and end points of a parametric curve from a
    restricted domain, and solve for $t$ when given a specific $x$- or
    $y$-value.
\end{enumerate}
\end{learningtargetbox}
