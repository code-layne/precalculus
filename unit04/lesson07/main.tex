\begin{skillbox}[{Vocabulary, Concepts, \& Theorems}]{greenbox}
\renewcommand{\arraystretch}{1.4}
\begin{tabularx}{\linewidth}{@{} >{\bfseries\color{navy}}p{0.27\linewidth} X @{}}
competing models  & Two or more regression models (linear, quadratic, exponential) fit to the same data set and compared for appropriateness. \\
residual          & The difference: actual $y$ minus predicted $\hat{y}$; written $e = y - \hat{y}$. \\
residual plot     & A graph of residuals vs.\ input values; a patternless scatter indicates a good model fit. \\
error             & The residual at a specific data point; positive = underestimate, negative = overestimate. \\
underestimate     & The model's prediction is \emph{less than} the actual value (positive error). \\
overestimate      & The model's prediction is \emph{greater than} the actual value (negative error). \\
\end{tabularx}
\end{skillbox}

\begin{skillbox}[Activate Prior Knowledge \& Spiral Review]{sky}
    Spiral review (warm-up) reinforces Lesson 2.5 skills: reading structure from a data table
    by computing successive differences and ratios, evaluating and comparing two function
    expressions at a given input, and identifying the type of model suggested by a constant ratio.
\end{skillbox}

\begin{skillbox}[Hook]{sky}
Display the following data on the board without context:

\medskip
\begin{center}
\begin{tabular}{c|c}
\textbf{Year ($x$)} & \textbf{Revenue (\$thousands)} \\ \hline
1 & 5   \\
2 & 11  \\
3 & 23  \\
4 & 47  \\
5 & 95  \\
\end{tabular}
\end{center}

\medskip
Ask: \textbf{``Could a straight line fit this? What about a curve? How do we decide?''}
After brief discussion, reveal the competition: a linear model gives $\hat{y} = 22.6x - 15.8$,
a quadratic gives $\hat{y} = 9.8x^2 - 18.2x + 13.4$, an exponential gives $\hat{y} = 2.56 \cdot 2^x$.
At $x = 5$: linear predicts 97.2, quadratic predicts 96.4, exponential predicts 81.9 --- actual
is 95. Today's lesson provides tools to decide which model is \emph{most appropriate}.
\end{skillbox}

\begin{skillbox}[Lesson]{sky}
\begin{multicols}{2}
\textbf{Part 1 (15 min): Reading Data Structure.}

Walk through computing first differences ($\Delta_1$), second differences ($\Delta_2$),
and successive ratios ($r$) on a 4-point data table in the guided notes:
\begin{itemize}[itemsep=2pt,topsep=2pt]
  \item Constant $\Delta_1$ $\Rightarrow$ \textbf{linear}
  \item Constant $\Delta_2$ $\Rightarrow$ \textbf{quadratic}
  \item Constant ratio $r$ $\Rightarrow$ \textbf{exponential}
\end{itemize}
Warn students: real data is messy; look for the \emph{nearly} constant quantity and use
contextual reasoning alongside the numbers.

\columnbreak

\textbf{Part 2 (15 min): Competing Regressions and Error.}

Given three regression equations for the same data (from technology output):
\begin{enumerate}[leftmargin=1.4em,itemsep=3pt,topsep=3pt]
  \item Evaluate each at a specific $x$.
  \item Compute error $= y_{\text{actual}} - \hat{y}$.
  \item Interpret the sign: $+$ means model underestimated; $-$ means it overestimated.
  \item Use a contextual clue (``grew faster every year'') to eliminate linear.
\end{enumerate}
\end{multicols}

\medskip
\textbf{Part 3 (10 min): Residual Plots and Model Validation.}

Define the residual plot: plot each $(x_i,\, y_i - \hat{y}_i)$.
Rule (EK 2.6.B.1): \emph{No pattern} $\Rightarrow$ model is appropriate.
Curved or systematic pattern $\Rightarrow$ wrong function type.
Show two contrasting descriptions: (a) linear fit to exponential data --- curved band in
residuals; (b) exponential fit --- scattered, no pattern.
Discuss preference: in safety engineering, an underestimate of load is dangerous; in budgeting,
an overestimate of cost is safer. Context, not just math, drives the final choice.
\end{skillbox}

\begin{skillbox}[Active Monitoring]{redbox}
\begin{itemize}[leftmargin=1.2em,itemsep=2pt,topsep=0pt]
  \item After Part 1: cold-call ``If second differences are constant but ratios are not,
        which model fits?'' Expect: quadratic.
  \item During Part 2: watch for students subtracting $y_{\text{actual}} - \hat{y}$ in the
        wrong order. Reinforce: error is always actual minus predicted.
  \item After Part 2: cold-call ``If error $= -4$, is the model an over- or underestimate?''
        Expect: overestimate (model predicted too high).
  \item During Part 3: probe ``What would a perfect-model residual plot look like?''
        Expect: points near zero, scattered randomly around the horizontal axis.
\end{itemize}
\end{skillbox}

\begin{skillbox}[Group Work \& Differentiation]{redbox}
\begin{itemize}[leftmargin=1.2em,itemsep=2pt,topsep=0pt]
  \item \textbf{Tier R (Remediate):} All three regressions pre-computed. Students evaluate each
        at a given $x$, compute errors, identify the model with smallest error, and connect to a
        contextual clue (``sales doubled each year'').
  \item \textbf{Tier A (Apply):} Students compute first and second differences and ratios from
        a data table; choose the likely model type; use technology to obtain regressions and $R^2$;
        justify the best-fitting model in writing.
  \item \textbf{Tier E (Extend):} Students analyze residuals from a linear model and an exponential
        model for the same data. They identify the pattern in the linear residuals, verify it
        disappears for the exponential model, and write a full justification combining residual
        evidence with contextual reasoning.
\end{itemize}
\end{skillbox}

\begin{skillbox}[Individual Work \& Assessment]{redbox}
Exit ticket (3 questions, 1 page): (1) compute first differences and ratios from a table, circle
the model type; (2) evaluate $\hat{y} = 3 \cdot 1.4^x$ at $x = 2$, compare to actual $y = 6.2$,
label over-/underestimate; (3) interpret a described residual plot (alternating positive/negative,
no pattern) in one sentence.

Sort by: miss item 1 $\Rightarrow$ review differences/ratios (LO 2.6.A);
miss item 2 $\Rightarrow$ reteach error formula (LO 2.6.B); miss item 3 $\Rightarrow$
residual plot interpretation (LO 2.6.B.1).
\end{skillbox}

\begin{skillbox}[Reinforcement \& Extension]{goldbox}
Homework (6 problems): classify a data set using differences and ratios; compare three models
at $x = 6$ and identify smallest error; contextual model choice (bacteria doubling); residual
plot comparison; AP-style MC from a regression table; extension computing sum of squared
residuals to determine the statistically better model.

Preview of Lesson 2.7: logarithmic functions as inverses of exponentials --- now that we can
validate which exponential model fits, students will learn how to solve for the input variable
(e.g., ``When does revenue exceed \$200{,}000?''), which requires inverting the exponential
function using a logarithm.
\end{skillbox}
