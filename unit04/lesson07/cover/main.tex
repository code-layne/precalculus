\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can construct and compare linear, quadratic, and exponential regression models for the
        same data set, using first differences, second differences, and successive ratios to
        determine which model type is most appropriate.
  \item I can compute the error (actual minus predicted) for a given model and interpret its sign
        as an underestimate or overestimate.
  \item I can interpret a residual plot to determine whether a model is appropriate, and use both
        contextual clues and statistical evidence to justify the best-fitting model.
\end{enumerate}
\end{learningtargetbox}
