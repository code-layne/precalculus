\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can write a parametric representation of an ellipse or circle given its standard
    form equation by using the substitution $x-h = a\cos t$, $y-k = b\sin t$.
  \item I can write a parametric representation of a parabola by introducing a parameter
    with the substitution $x(t) = h+t$ (or $y(t) = k+t$ for sideways parabolas).
  \item I can use parametric analysis --- finding extrema from component functions and
    axis intercepts from zeros --- on a parametrized implicit curve.
\end{enumerate}
\end{learningtargetbox}
