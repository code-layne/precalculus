\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can write a parametric model for circular motion using transformations
    of $(x(t),\,y(t)) = (\cos t,\,\sin t)$, identifying the radius, center,
    and orientation from the equations.
  \item I can parametrize the line segment between two given points using an
    initial position and constant rates of change, and evaluate the
    parametrization at any value of $t$.
  \item I can interpret the parameters in a circular or linear parametrization
    in a contextual setting, including finding when a circular path reaches a
    maximum or minimum height.
\end{enumerate}
\end{learningtargetbox}
