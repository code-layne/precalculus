\begin{notesbox}{Exit Ticket Key}

\textbf{1.}\quad Using the cafeteria transition matrix $T = \begin{bmatrix}0.7&0.4\\0.3&0.6\end{bmatrix}$
and the Day~1 state $\vec{s}_1 = \begin{bmatrix}102\\78\end{bmatrix}$,
compute $\vec{s}_2 = T\vec{s}_1$. Show your work.

\vspace{6pt}
Row 1: $0.7(102)+0.4(78) = \ans{71.4+31.2=102.6}$

\vspace{4pt}
Row 2: $0.3(102)+0.6(78) = \ans{30.6+46.8=77.4}$

\vspace{6pt}
$\vec{s}_2 = \ans{$\begin{bmatrix}102.6 \\ 77.4\end{bmatrix}$}$

\vspace{14pt}
\textbf{2.}\quad A steady state $\vec{s}_\infty$ satisfies $T\vec{s}_\infty = \vec{s}_\infty$.
If the total is always $p + q = 180$ and the first row gives $0.7p + 0.4q = p$,
solve for $p$ and $q$.

\vspace{4pt}
Show work:

\ans{$0.7p+0.4q=p$ $\Rightarrow$ $0.4q=0.3p$ $\Rightarrow$ $p=\dfrac{4q}{3}$.\\[3pt]
Substitute into $p+q=180$: $\dfrac{4q}{3}+q=180$ $\Rightarrow$ $\dfrac{7q}{3}=180$ $\Rightarrow$ $q=\dfrac{540}{7}\approx77.1$.\\[3pt]
Then $p=180-77.1\approx102.9$.}

\vspace{6pt}
$p \approx \ans{102.9}$ \qquad $q \approx \ans{77.1}$

\vspace{10pt}
\textbf{3.}\quad Would $T^{-1}\vec{s}_1$ give the Day~0 state or the Day~2 state?
Explain in one sentence.

\vspace{4pt}
\ansline{Day~0 --- multiplying by $T^{-1}$ reverses one transition step, recovering the state that came before $\vec{s}_1$.}
