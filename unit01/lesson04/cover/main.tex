\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can sort a transformation rule into a change to the \textit{question}
        handed to the parent function or a change to the \textit{answer} it
        hands back.
  \item I can describe a vertical translation, a vertical dilation, and a
        reflection from the numbers written outside the function.
  \item I can explain why a change inside the parentheses moves the graph in
        the direction the sign does not suggest --- by solving for the input.
  \item I can follow a landmark point from the parent graph to the transformed
        graph, even when several moves are combined.
  \item I can state the domain and range of a transformed function, and say
        which part of the rule moved each one.
\end{enumerate}
\end{learningtargetbox}

\begin{remindbox}
\small
Using a function is a transaction: you hand it a question, it hands back an
answer. Every rule today interferes at exactly one of those two places.
Outside the function, the rule rewrites the \textit{answer} --- vertical, and
it does what it says. Inside the parentheses, it rewrites the
\textit{question} --- horizontal, and it runs opposite to what it looks like,
because you have to solve for the input that makes the question come out
right. Nothing here needs memorizing if you follow one landmark point through.
\end{remindbox}
