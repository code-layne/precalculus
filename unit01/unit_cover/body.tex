\small\textbf{Unit Overview.}
This unit is about the single idea every later unit is built on: a
\textbf{function} is a rule that pairs each input with exactly one output. It
learns to \emph{read} that rule --- in notation, in a table, and in a graph,
including a piecewise rule that changes with the input --- and then to
\emph{build} with it: adding, subtracting, multiplying, and dividing functions,
and feeding one function into another. Unit 2 takes this toolkit to the graphs
themselves: the library of parent functions, transformations, symmetry and
inverses, and the characteristics and rates of change of a graph.
\end{tcolorbox}

\begin{remindbox}
\small
\textbf{Two questions carry the whole unit:} \emph{How do we describe the way one
quantity changes with respect to another?} and \emph{How do we build a new
function out of ones we already have?} Keep them in view --- every lesson here
answers one of the two, and the unit test asks you to do both.
\end{remindbox}
