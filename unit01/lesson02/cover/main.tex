\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can describe how a function's output changes as its input increases,
        and name the intervals where the function is increasing or decreasing.
  \item I can decide whether a graph is concave up or concave down by checking
        whether the rate of change is growing or shrinking.
  \item I can identify the zeros of a function from a graph or a table and
        explain what a zero means in context.
\end{enumerate}
\end{learningtargetbox}

\begin{remindbox}
\small
Last lesson every function got a name and we learned to run the machine.
Today we stand back and watch two quantities move \textbf{in tandem}: as the
input climbs, does the output rise or fall --- and is that change speeding up
or slowing down? Four new words --- \textbf{increasing}, \textbf{decreasing},
\textbf{concave up}, \textbf{concave down} --- plus the \textbf{zeros} where a
graph touches down.
\end{remindbox}
