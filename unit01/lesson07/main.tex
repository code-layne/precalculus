\begin{itemize}[leftmargin=1.2em,itemsep=2pt,topsep=0pt]
  \item Constant 1st differences $\Rightarrow$ linear; constant 2nd differences $\Rightarrow$

\begin{skillbox}[{Vocabulary, Concepts, \& Theorems}]{greenbox}
\renewcommand{\arraystretch}{1.4}
\begin{tabularx}{\linewidth}{@{} >{\leavevmode\bfseries\color{navy}}p{0.30\linewidth} X @{}}
First differences    & The differences between consecutive output values of equally-spaced inputs: $\Delta y_i = y_{i+1} - y_i$. \\
Second differences   & Differences of the first differences; constant for quadratic models. \\
$n$th differences    & Differences taken $n$ times; constant and nonzero for degree-$n$ polynomial models. \\
Domain restriction   & A limit on the input values that is mathematically, contextually, or practically required. \\
Range restriction    & A limit on the output values (e.g., integer-only outputs due to rounding). \\
Piecewise-defined function & A function defined by different formulas over different intervals of its domain. \\
Model assumption     & A simplifying claim about the real world that must hold for the model to be valid. \\
\end{tabularx}
\end{skillbox}

\begin{skillbox}[Hook]{sky}
``A scientist hands you a table of mystery data. How do you decide which function type to use?''

\medskip
Display a short table with six equally-spaced inputs and outputs. Ask cold-call: ``Is this
linear, quadratic, or something else? How can you tell without graphing it?'' Let students
debate for 90 seconds before revealing the difference-table approach.
\end{skillbox}

\begin{skillbox}[Lesson]{sky}
\begin{multicols}{2}
\textbf{Part 1 (12 min): Difference-Table Decision Tree.}

Given a table with equally-spaced inputs, compute differences:
\begin{enumerate}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
  \item Compute 1st differences ($\Delta y$).
  \item If constant $\Rightarrow$ \textbf{linear} (degree 1).
  \item If not constant, compute 2nd differences ($\Delta^2 y$).
  \item If constant $\Rightarrow$ \textbf{quadratic} (degree 2).
  \item Continue: constant $n$th differences $\Rightarrow$ degree-$n$ polynomial.
\end{enumerate}

Pose: ``If 1st differences grow linearly themselves, what does that tell you?'' (Answer: 2nd
differences are constant, so the data is quadratic.)

\columnbreak

\textbf{Part 2 (10 min): Shape \& Context Clues.}

When no table is given, use context:
\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
  \item Roughly constant rate of change $\Rightarrow$ linear.
  \item Area or 2-D measurement $\Rightarrow$ quadratic.
  \item Volume or 3-D measurement $\Rightarrow$ cubic.
  \item Multiple local maxima/minima or multiple real zeros $\Rightarrow$ higher-degree polynomial.
  \item Behavior changes abruptly at a threshold $\Rightarrow$ piecewise.
\end{itemize}

\textbf{Part 3 (10 min): Stating Assumptions (LO 1.13.B).}

Every model rests on assumptions. Template: ``This model assumes that
[quantity/behavior] remains [consistent/proportional/valid] over [domain interval].
The domain is restricted to [values] because [mathematical / contextual reason].''

Walk through a fencing example: ``We model the enclosed area as a quadratic in side length.
We assume the fencing forms a perfect rectangle and that side length is between 0 and half
the total fencing available.''
\end{multicols}
\end{skillbox}

\begin{skillbox}[Active Monitoring]{redbox}
\begin{itemize}[leftmargin=1.2em,itemsep=2pt,topsep=0pt]
  \item After Part 1: cold-call ``If 3rd differences are constant, what degree polynomial models the data?''
  \item After Part 2: cold-call ``Why can't you model negative time in the fencing problem?'' (domain restriction)
  \item Watch for students who compute differences but stop at 1st differences even when they are not constant.
  \item Watch for students who confuse \textit{contextual} domain restrictions (e.g., length $> 0$) with
        \textit{mathematical} ones (e.g., denominator $\neq 0$).
  \item After Part 3: cold-call ``What would constant second differences tell you?'' --- expect ``the data
        is quadratic'' or ``the rate of change is linear.''
\end{itemize}
\end{skillbox}

\begin{skillbox}[Group Work \& Differentiation]{redbox}
\begin{itemize}[leftmargin=1.2em,itemsep=2pt,topsep=0pt]
  \item \textbf{Tier R (Remediate):} Given four scenarios with model type choices; circle the best model
        and complete a fill-in assumption sentence.
  \item \textbf{Tier A (Apply):} Compute difference tables for provided data, determine degree, name the
        model type, and state one assumption with domain restriction.
  \item \textbf{Tier E (Extend):} Write a piecewise model description (two pieces, each with appropriate
        function type) for a real-world scenario and articulate two assumptions with justification.
\end{itemize}
\end{skillbox}

\begin{skillbox}[Individual Work \& Assessment]{redbox}
Exit ticket (3 questions, 1 page): (1) complete a first/second differences table and name the
model type; (2) read a scenario description and circle the best model with one reason; (3) state
one domain restriction and one assumption for a fencing model. Collect and use to group students
before Lesson 1.14.
\end{skillbox}

\begin{skillbox}[Reinforcement \& Extension]{goldbox}
Homework: 5--6 problems covering difference tables, context-to-model matching, assumption
articulation, and piecewise model description. Extension: given 4 data points, write the
unique cubic model in descriptive form and state what real-world meaning the degree implies.
Preview of Lesson 1.14: students will \textit{construct} function models from scratch --- today's
selection and assumption skills are the prerequisite.
\end{skillbox}
