\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can decide what kind of function fits a data set by taking first and
        second differences of equally spaced inputs.
  \item I can choose a model type from the context alone --- area, volume,
        inverse proportion, or a rule that changes at a threshold.
  \item I can build a function model from a constraint by solving for one
        variable and substituting, and I can state the domain the context
        allows.
  \item I can use a model: evaluate it, find an average rate of change
        \textit{with units}, and name the assumption it rests on.
\end{enumerate}
\end{learningtargetbox}

\begin{remindbox}
\small
Every lesson so far has handed you a function. Today you pick one, and then you
build it. A table tells you which type through its \textbf{differences}; a
context tells you through its \textbf{shape}. Then a single constraint --- ``the
fencing totals 80 feet'' --- turns two unknowns into one, and you have a model.
The last step is the one people skip: say what the model assumes, and say which
inputs it is allowed to take.
\end{remindbox}
