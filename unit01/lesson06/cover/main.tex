\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can use $f^{-1}$ to give back the \textit{question} that produced a
        given answer --- if $f(a) = b$, then $f^{-1}(b) = a$.
  \item I can explain why $f^{-1}(x)$ is not $\dfrac{1}{f(x)}$, using numbers
        rather than a slogan.
  \item I can build $f^{-1}$ from a table by trading rows, and say why the
        domain and range trade places.
  \item I can decide whether a function is one-to-one, and restrict its domain
        when it is not.
  \item I can find $f^{-1}(x)$ by swapping and solving, and verify the pair by
        composition in both directions.
\end{enumerate}
\end{learningtargetbox}

\begin{remindbox}
\small
Last lesson two functions ran back to back, and one number sat between them:
the \textbf{handoff}, an answer and a question at the same time. Today we run
a single function backwards. A function takes a \textit{question} to an
\textit{answer}; its \textbf{inverse} takes the answer back to the question.
That one sentence is the whole lesson. It is why the domain and range trade
places, why the graphs mirror across $y = x$, why $f^{-1}(x)$ has nothing to do
with $\dfrac{1}{f(x)}$, and why a function whose answer came from two different
questions has no inverse at all until you throw some questions away.
\end{remindbox}
