\begin{notesbox}{Increasing, Decreasing, \& Concavity}
\textbf{Formal Definitions:}

A function $f$ is \textbf{increasing} on an interval if, for any $a < b$ in that interval,
$f(a)$ \blank{0.8cm} $f(b)$.

A function $f$ is \textbf{decreasing} on an interval if, for any $a < b$ in that interval,
$f(a)$ \blank{0.8cm} $f(b)$.

\medskip
\textbf{Concavity} describes whether the rate of change is itself increasing or decreasing:

\begin{itemize}
  \item \textbf{Concave up:} the rate of change is \blank{2.5cm}
        (graph curves like a bowl that opens \blank{1.5cm}).
  \item \textbf{Concave down:} the rate of change is \blank{2.5cm}
        (graph curves like a hill that opens \blank{1.5cm}).
\end{itemize}
