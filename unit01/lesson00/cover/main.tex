\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can identify the input and output quantities in a real-world relationship
        and decide which one depends on the other.
  \item I can explain in my own words what makes a relationship a function: each
        input produces exactly one output.
  \item I can read a graph or a table of a changing quantity and describe where
        it is increasing, decreasing, or constant.
\end{enumerate}
\end{learningtargetbox}
