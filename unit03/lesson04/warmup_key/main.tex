  \item Between $\theta=0$ and $\theta=\dfrac{\pi}{2}$, is $\sin\theta$ increasing or
        decreasing? Explain how you know using the unit circle.

        \vspace{0.08in}
        \ansline{Increasing.} As $\theta$ increases from $0$ to $\dfrac{\pi}{2}$, the
        point on the unit circle moves from $(1,0)$ upward to $(0,1)$, so the
        $y$-coordinate (which equals $\sin\theta$) rises from $0$ to $1$.
