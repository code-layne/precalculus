\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can rewrite trigonometric expressions using the Pythagorean identity
    $\sin^2\theta + \cos^2\theta = 1$ and its derived forms
    $1 + \tan^2\theta = \sec^2\theta$ and $\cot^2\theta + 1 = \csc^2\theta$.
    \hfill\textit{(LO 3.12.A)}
  \item I can use the sum, difference, and double-angle identities for sine and cosine
    to rewrite expressions in equivalent forms and to find exact values of trig functions
    at non-standard angles. \hfill\textit{(LO 3.12.B)}
  \item I can solve trigonometric equations by substituting an equivalent form to convert
    the equation into a single-function algebraic equation, then find all solutions in a
    given interval. \hfill\textit{(LO 3.12.C)}
\end{enumerate}
\end{learningtargetbox}
