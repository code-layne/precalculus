\item \textbf{(AP-Style Multiple Choice)} Which of the following is equivalent to $\log_b c = 5$?

      \medskip
      \begin{enumerate}[label=(\Alph*), itemsep=4pt]
        \item $b^c = 5$
        \item $c^5 = b$
        \item $b^5 = c$
        \item $5^b = c$
      \end{enumerate}

      \vspace{0.04in}
      Answer: \textit{Letter:}~\gradedblank[id=hw6, type=choice, points=1, answer=C]{1.5cm}{13pt} \quad By the definition $\log_b c = 5 \Leftrightarrow b^5 = c$.
