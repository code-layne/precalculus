\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can express an arithmetic sequence as a function $a_n = a_0 + dn$ and identify its
        common difference.
  \item I can express a geometric sequence as a function $g_n = g_0 r^n$ and identify its
        common ratio.
  \item I can compare how arithmetic and geometric sequences change across successive terms.
\end{enumerate}
\end{learningtargetbox}
