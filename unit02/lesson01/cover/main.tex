\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can use the \textbf{imaginary unit} $i = \sqrt{-1}$ to rewrite the square root of a
        negative number, solve an equation like $x^2 + 16 = 0$, and find a power of $i$.
  \item I can add, subtract, and multiply \textbf{complex numbers} in the form $a + bi$, and
        multiply a number by its \textbf{complex conjugate}.
  \item I can name the ten \textbf{parent functions} in the library from an equation, a graph,
        or key points, and read each one's domain and range from its graph.
  \item I can write an \textbf{absolute value} such as $|x - 2|$ as a piecewise function and
        evaluate it --- knowing that $-x$ means \emph{the opposite of} $x$.
\end{enumerate}
\end{learningtargetbox}

\begin{remindbox}
\small
No real number squares to a negative, so we name one that does: $i$, with $i^2 = -1$.
\textbf{Rewrite with $i$ first}, then compute. The \textbf{parent functions} are ten shapes
to know by sight --- every graph in the next lesson is one of them, moved. And the absolute
value is a piecewise function in disguise: in $|x| = -x$ for $x < 0$, the $-x$ means
\textbf{the opposite of $x$}, which is positive whenever $x$ is negative.
\end{remindbox}
