\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can determine the input-output pairs of the inverse of a function from a table or a
        set of ordered pairs, and I can explain when a function is invertible on a given domain.
        \hfill\textit{(LO 2.8.A)}
  \item I can find the inverse of a function analytically by swapping $x$ and $y$ and solving,
        and I can verify the result using composition: $f(f^{-1}(x)) = x$.
        \hfill\textit{(LO 2.8.B)}
  \item I can restrict the domain of a non-invertible function to make it invertible, and I can
        identify the domain and range of both $f$ and $f^{-1}$.
        \hfill\textit{(LO 2.8.B)}
\end{enumerate}
\end{learningtargetbox}
