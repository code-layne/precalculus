\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can describe a \textit{translation}: $f(x) + k$ moves a graph up or down, and
        $f(x - h)$ moves it right or left --- and I can explain why $f(x + 3)$ moves it
        \textbf{left}.
  \item I can describe a \textit{reflection}: $-f(x)$ flips a graph over the $x$-axis and
        $f(-x)$ flips it over the $y$-axis.
  \item I can describe a \textit{dilation}: $a\,f(x)$ stretches or compresses a graph
        vertically by $|a|$, and $f(bx)$ stretches or compresses it horizontally by
        $\tfrac{1}{|b|}$.
  \item I can combine all of them in $g(x) = a\,f\big(b(x - h)\big) + k$: map key points from
        a parent graph, describe the moves in order, and write the equation of a transformed
        graph.
\end{enumerate}
\end{learningtargetbox}

\begin{remindbox}
\small
Every parent function from 2.1 can be moved, flipped, and resized without learning a new
graph. A change \textbf{outside} the function acts on the outputs, so it moves the graph up
and down and does exactly what it says. A change \textbf{inside} the function acts on the
inputs before the function ever sees them --- a composition --- so it moves the graph left
and right and seems to run \textbf{backwards}.
\end{remindbox}
