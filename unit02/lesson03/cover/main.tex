\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can identify the initial value $a$ and base $b$ of $f(x) = ab^x$ and classify the
        function as exponential growth or decay.
  \item I can describe the domain, end behavior, concavity, and monotonic nature of an
        exponential function.
  \item I can determine whether a function is exponential by checking whether outputs are
        proportional over equal-length input intervals.
\end{enumerate}
\end{learningtargetbox}
