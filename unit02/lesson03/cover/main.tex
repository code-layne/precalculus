\begin{learningtargetbox}
\small
\begin{enumerate}[leftmargin=1.5em, itemsep=5pt]
  \item I can decide whether a function is \textbf{even}, \textbf{odd}, or \textbf{neither} ---
        from its graph, by its symmetry over the $y$-axis or about the origin, and with algebra,
        by comparing $f(-x)$ with $f(x)$ and with $-f(x)$.
  \item I can decide whether a function is \textbf{one-to-one}, and read its \textbf{inverse}
        from a table or a graph: if $f(a) = b$, then $f^{-1}(b) = a$, and every point $(a, b)$
        becomes $(b, a)$ --- a reflection over the line $y = x$.
  \item I can find the inverse of a function from its formula, check it with composition, and
        restrict the domain of a function like $x^2$ so that it has an inverse.
\end{enumerate}
\end{learningtargetbox}

\begin{remindbox}
\small
Today is about three kinds of symmetry. An \textbf{even} function's graph is a mirror image of
itself over the $y$-axis. An \textbf{odd} function's graph lands on itself after a half turn
about the origin. And a function and its \textbf{inverse} are mirror images of each other over
the line $y = x$: the inverse swaps every input with its output, so it runs the function
backward. The $-1$ in $f^{-1}$ is a name, not an exponent --- $f^{-1}$ is never $1/f$.
\end{remindbox}
